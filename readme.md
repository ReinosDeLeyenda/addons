# Addons para WoW 3.3.5a — Reinos de Leyenda

Colección de addons personalizados, optimizados y corregidos para **World of Warcraft: Wrath of the Lich King (3.3.5a)**, especialmente pensados para jugar en **Reinos de Leyenda** y hermandades grandes.

---

## 📦 Contenido del repositorio

### Addons personalizados y mejorados
* **`ModernUI`** *(antes `ModernCharacterUI`)*: Unifica y moderniza la ventana de personaje, mascotas, monturas, recetas de profesión y vista de vendedores, con comprobación automática de versiones (`/modernui version`).
* **`IceLFD`**: Rediseña el buscador de mazmorras con temática azul hielo, muestra el nivel de objeto (`iLvl`), equipamiento y progreso de mazmorras del grupo, e incluye avisos de actualización (`/icelfd ver`).
* **`GTFO`**: Alerta sonora cuando pisas áreas de daño en banda o mazmorra, con sistema inteligente de avisos por chat de banda/grupo sin mensajes duplicados ni falsos positivos en ataques de tanque.
* **`ReinosDeLeyenda_ReagentBank`**: Utilidades y gestión para el banco de materiales del servidor.

### Addons optimizados para hermandades grandes
* **`Prat-3.0`** *(+ módulos y librerías)*: Mejora del chat optimizada para evitar caídas de rendimiento en hermandades con muchos miembros conectados.
* **`FollowFelankor`**: Seguimiento automático mejorado y sin errores en grupo/banda.
* **`DataStore`** *(+ todos sus módulos: `Achievements`, `Auctions`, `Characters`, `Containers`, `Crafts`, `Currencies`, `Inventory`, `Mails`, `Pets`, `Quests`, `Reputations`, `Skills`, `Spells`, `Stats`, `Talents`)*: Base de datos de personajes necesaria para addons como Altoholic, optimizada para reducir el consumo de memoria y tráfico de red.

## 🚀 Cómo instalarlos

1. Pulsa el botón verde **`<> Code`** arriba a la derecha y selecciona **`Download ZIP`**.
2. Extrae el archivo `.zip` en tu ordenador.
3. Copia las carpetas de los addons que quieras usar (por ejemplo `ModernUI`, `IceLFD`, `GTFO`, `Prat-3.0`, etc.) dentro de tu carpeta del juego:
   ```text
   World of Warcraft\Interface\AddOns\
   ```
   > **Importante:** Asegúrate de que dentro de cada carpeta de addon estén directamente sus archivos (`.toc`, `.lua`, etc.) y no una subcarpeta intermedia.
4. Inicia sesión en el juego y verifica en el botón **Accesorios** (abajo a la izquierda en la pantalla de selección de personaje) que estén activados.
